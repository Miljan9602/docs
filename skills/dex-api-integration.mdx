# Dragonswap DEX API - Integration Reference

## Quick Reference

| Property | Value |
|----------|-------|
| Base URL | `https://sei-api.dragonswap.app` |
| API Prefix | `/api/v1/` (data) · `/api/v4/` (routing) — always with `/api`; `/v1/...` returns 404 |
| Authentication | None needed for the endpoints documented here |
| Chain | Sei Network (pacific-1) |
| Chain ID | `1329` |
| SplitRouter | `0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199` |
| Staking contract | `0xb71886c52d754cf2b1d3d866c7cfe9eec01418a7` |
| Response Format | Data: `{ "status": "ok", ... }` (`/api/v1/vol` has no `status`). Quote: `{ "status": "success", ... }`. Errors: see Errors below |
| CORS | Allowlisted origins only — call the API from a server, not from a browser on your domain |
| Caching | Cloudflare-cached; responses can be up to ~2 min old |

## Overview

The Dragonswap DEX API provides read-only access to pools, tokens, farms, staking, incentives, airdrops, user data, and swap quoting on the Sei Network. The quoting flow is two-step: fetch an optimal route via the API, then call the on-chain SplitRouter for exact amounts and price impact (required for `exactOut`).

## Conventions

- **Pool naming:** API `V2_POOL` / `v2` = DEX V1 (constant-product) pool; `V3_POOL` / `v3` = DEX V2 (concentrated-liquidity) pool. The quote API and SplitRouter use `poolType` `0` = V1, `1` = V2.
- **Addresses:** path addresses are case-insensitive. Quote token addresses must be EIP-55 checksummed or all-lowercase.
- **Timestamps:** Unix seconds, as numbers — except in staking endpoints, where they are strings: emissions and rewards `created_at`, staking activity `timestamp`, user stakings payout `blockTimestamp`.
- **Amounts:** token amounts are decimal-adjusted numbers (pool reserves, swap amounts, farm amounts, incentive `reward`, staking emissions `amount`, `drg_fee`); staking bonus `amount` and airdrop `amounts` are decimal strings. Wei amounts are strings (`*_wei` fields, staking user-stats values, user stakings `amount`, quote `dex.inputAmount` / `dex.outputAmount`).
- **USD values:** numbers, except decimal strings for incentive `liquidity_usd` and `apr` and staking bonus `amount_usd_value`. `hourly_*` and `*_change_24h` fields can be `null`.
- **24-hour fields:** `daily_volume` and `daily_fees` are rolling last-24-hour values. `daily_transactions` is a cumulative count, not a 24-hour count.
- **Ended programs stay listed:** farms (`end_timestamp`), incentives (`end_time`) and airdrops (`ends_at`) — compare with the current time to find active ones.
- **Snapshot series** are sorted oldest first; the last entry is the latest snapshot. Pool and token stats: `daily` (24 hours), `weekly` (7 days), `monthly` (1 month), `quarterly` (3 months), `all_time` (last 12 months, not full history). Staking stats: `daily`, `weekly`, `monthly`, `all_time`.

## Errors

| Case | HTTP | Body |
|------|------|------|
| Unknown route (gateway) | 404 | `404 page not found` (text/plain, not JSON) |
| Wrong HTTP method (gateway) | 405 | `405 method not allowed` (text/plain) |
| Token not found | 404 | `{"status":"fail","error":{"code":404,"type":"token_not_found","message":"Token not found"}}` |
| Pool or farm not found | 404 | `{"status":"error","error":{"code":404,"type":"pool_not_found","message":"Pool does not exist."}}` (farms: `farm_not_found`, `Farm does not exist.`) |
| Staking `{address}` is not the staking contract (activity, user stats) | 404 | `{"status":"fail","error":{"code":404,"type":"staker_address_not_found","message":"Staker address not found"}}` |
| Airdrop not found | 404 | `{"status":"fail"}` |
| Quote validation | 400 | `{"status":"error","message":[{ "code", "path", "message", ... }]}` |
| Quote: no route, `amount` `0` or non-integer | 500 | `{"status":"error","message":"..."}` |

Many lookups return `200` with empty data instead of a 404; each endpoint below notes this. An invalid address on `/api/v1/user/{address}/portfolio`, and `0` for a pool-stats query parameter, return HTTP 500.

## Quoting Flow (Two-Step)

### Step 1 — Route Discovery

```
GET https://sei-api.dragonswap.app/api/v4/quote
```

Finds the optimal swap route across all available Dragonswap pools and returns the expected amounts for that route.

#### Query Parameters

<ParamField query="amount" type="string" required>
  Amount in the token's smallest unit, as a base-10 integer string (e.g. `1000000000000000000` = 1 WSEI, `1000000` = 1 USDC). For `exactIn` this is the input amount; for `exactOut` it is the desired output amount. A non-integer value or `0` returns a `500` error.
</ParamField>

<ParamField query="tokenInAddress" type="string" required>
  Input token contract address (0x-prefixed). Use the EIP-55 checksummed form or all-lowercase — a mixed-case address with an invalid checksum returns `400` `Not an address`.
</ParamField>

<ParamField query="tokenOutAddress" type="string" required>
  Output token contract address (0x-prefixed). Same format rules as `tokenInAddress`.
</ParamField>

<ParamField query="type" type="string" required>
  Quote direction: `exactIn` or `exactOut` (case-sensitive). The value is not validated as an enum — any other value (e.g. `exactout`) is quoted as `exactIn`.
</ParamField>

#### Response

<ResponseField name="status" type="string">
  `"success"` or `"error"`
</ResponseField>

<ResponseField name="type" type="string">
  Quote source. `"dex"` for a route through Dragonswap pools, described by the `dex` object.
</ResponseField>

<ResponseField name="dex" type="object">
  The routing result.
</ResponseField>

<ResponseField name="dex.inputAmount" type="string">
  Input amount in wei of `tokenInAddress`. For `exactIn` this equals `amount`. Do not use it for `exactOut` quotes — see the warning below.
</ResponseField>

<ResponseField name="dex.outputAmount" type="string">
  Expected output amount in wei of `tokenOutAddress`. Do not use it for `exactOut` quotes — see the warning below.
</ResponseField>

<ResponseField name="dex.impactPips" type="string">
  Price impact in millionths (`1000000` = 100%, `10000` = 1%), excluding LP fees. Same scale as `impactPips` returned on-chain.
</ResponseField>

<ResponseField name="dex.route" type="array">
  Array of pool hops defining the swap path. Each hop maps directly to a `SwapParams` struct and contains:
  - `pool` (string) — Pool contract address (EIP-55 checksummed)
  - `poolType` (number) — `0` = V1, `1` = V2
  - `inputToken` (string) — Input token address for this hop
  - `outputToken` (string) — Output token address for this hop
  - `feePips` (number) — Pool fee in pips (1 pip = 0.0001%, so `3000` = 0.3%)
  - `inputPercentage` (number) — Share (0–100) of the remaining, not-yet-routed balance of `inputToken` that this hop takes. Hops are applied in route order, so a 95% / 5% split of the input shows up as `95` on the first hop and `100` on the hop that takes the remaining 5%.
  - `outputPercentage` (number) — Output-side split value used by the SplitRouter. Pass it through unchanged; for the share of the total handled by each path, see `dex.linearSubroutes`.
</ResponseField>

<ResponseField name="dex.linearSubroutes" type="array">
  Per-path view of the route. Each subroute contains:
  - `percentage` (number) — Share (0–100) of the total swap going through this path
  - `swaps` (array) — Hops on this path, with the same fields as `dex.route` minus the percentage fields
</ResponseField>

<ResponseField name="rfq" type="null">
  `null` in DEX responses (`type: "dex"`). RFQ quotes are documented in the [RFQ section](/frontend/getting-started).
</ResponseField>

<ResponseField name="rfqConfig" type="null">
  `null` in DEX responses (`type: "dex"`).
</ResponseField>

<ResponseField name="unwrap" type="boolean">
  Included in `exactIn` responses; omitted from `exactOut` responses.
</ResponseField>

<ResponseField name="message" type="array | string">
  Only when `status` is `"error"`. An array of validation issues (HTTP `400`), or a string (HTTP `500`) — returned, for example, when no route exists between the two tokens or `amount` is `0` or not an integer.
</ResponseField>

<Warning>
  For `exactOut` quotes, do not use `dex.inputAmount` or `dex.outputAmount`: `dex.outputAmount` can be lower than the requested `amount`, and `dex.inputAmount` can be lower than the input actually required. Use `dex.route` and get the amounts from on-chain `quoteExactOutput` (Step 2 below).
</Warning>

<Info>
  For `exactIn` quotes, `dex.outputAmount` and `dex.impactPips` match what `quoteExactInput` returns for the same route at the time of the request, so Step 2 is optional for displaying a quote. Re-quote on-chain right before executing a swap, since pool state changes every block.
</Info>

### Step 2 — On-chain Quote via SplitRouter

Call `DragonswapSplitRouter` at [`0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199`](https://seitrace.com/address/0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199) via `simulateContract` (read-only `eth_call`). The quote functions are declared `nonpayable` rather than `view`, which is why `simulateContract` is used.

| Function | Direction | Returns |
|---|---|---|
| `quoteExactInput(ExactInputParams)` | exactIn | `(uint256 inputAmount, uint256 outputAmount, uint256 impactPips)` |
| `quoteExactOutput(ExactOutputParams)` | exactOut | `(uint256 inputAmount, uint256 outputAmount, uint256 impactPips)` |

`impactPips` is the price impact in millionths (`1000000` = 100%, so `7744` ≈ 0.77%), excluding LP fees.

**Structs:**

| Struct | Fields |
|--------|--------|
| `ExactInputParams` | `inputAmount` (uint256), `minOutputAmount` (uint256, `0n`), `deadline` (uint256, `0n`), `unwrap` (bool, `false`), `route` (`SwapParams[]`) |
| `ExactOutputParams` | `outputAmount` (uint256), `maxInputAmount` (uint256, `0n`), `deadline` (uint256, `0n`), `unwrap` (bool, `false`), `route` (`SwapParams[]`) |
| `SwapParams` | `poolType` (uint8, `0` = V1, `1` = V2), `pool` (address), `inputToken` (address), `outputToken` (address), `feePips` (uint24), `inputPercentage` (uint8), `outputPercentage` (uint8) |

<Info>
  `minOutputAmount`, `maxInputAmount`, `deadline`, and `unwrap` are **ignored** during quoting — set them to `0n`, `0n`, `0n`, and `false` respectively.
</Info>

### Full Example (viem/TypeScript)

Each entry in `data.dex.route` maps directly to a `SwapParams` struct.

```typescript
import { createPublicClient, http, parseAbi } from "viem";
import { sei } from "viem/chains";

const publicClient = createPublicClient({
  chain: sei,
  transport: http(),
});

const SPLIT_ROUTER = "0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199" as const;

const splitRouterAbi = parseAbi([
  "struct SwapParams { uint8 poolType; address pool; address inputToken; address outputToken; uint24 feePips; uint8 inputPercentage; uint8 outputPercentage; }",
  "struct ExactInputParams { uint256 inputAmount; uint256 minOutputAmount; uint256 deadline; bool unwrap; SwapParams[] route; }",
  "struct ExactOutputParams { uint256 outputAmount; uint256 maxInputAmount; uint256 deadline; bool unwrap; SwapParams[] route; }",
  "function quoteExactInput(ExactInputParams params) external returns (uint256 inputAmount, uint256 outputAmount, uint256 impactPips)",
  "function quoteExactOutput(ExactOutputParams params) external returns (uint256 inputAmount, uint256 outputAmount, uint256 impactPips)",
]);

type SwapParams = {
  poolType: number;
  pool: `0x${string}`;
  inputToken: `0x${string}`;
  outputToken: `0x${string}`;
  feePips: number;
  inputPercentage: number;
  outputPercentage: number;
};

type RouteResponse =
  | { status: "success"; dex: { route: SwapParams[] } }
  | { status: "error"; message: unknown };

async function getQuote(
  tokenIn: string,
  tokenOut: string,
  amount: string,
  type: "exactIn" | "exactOut"
) {
  // Step 1: Get optimal route from the API
  const params = new URLSearchParams({
    amount,
    tokenInAddress: tokenIn,
    tokenOutAddress: tokenOut,
    type,
  });

  const res = await fetch(
    `https://sei-api.dragonswap.app/api/v4/quote?${params}`
  );
  const data = (await res.json()) as RouteResponse;

  if (data.status !== "success") {
    throw new Error(`Route discovery failed: ${JSON.stringify(data.message)}`);
  }

  // Map API route to SwapParams structs
  const route = data.dex.route.map((hop) => ({
    poolType: hop.poolType,
    pool: hop.pool,
    inputToken: hop.inputToken,
    outputToken: hop.outputToken,
    feePips: hop.feePips,
    inputPercentage: hop.inputPercentage,
    outputPercentage: hop.outputPercentage,
  }));

  // Step 2: Call the on-chain quote function
  if (type === "exactIn") {
    const { result } = await publicClient.simulateContract({
      address: SPLIT_ROUTER,
      abi: splitRouterAbi,
      functionName: "quoteExactInput",
      args: [
        {
          inputAmount: BigInt(amount),
          minOutputAmount: 0n,
          deadline: 0n,
          unwrap: false,
          route,
        },
      ],
    });

    const [inputAmount, outputAmount, impactPips] = result;
    return { inputAmount, outputAmount, impactPips };
  }

  const { result } = await publicClient.simulateContract({
    address: SPLIT_ROUTER,
    abi: splitRouterAbi,
    functionName: "quoteExactOutput",
    args: [
      {
        outputAmount: BigInt(amount),
        maxInputAmount: 0n,
        deadline: 0n,
        unwrap: false,
        route,
      },
    ],
  });

  const [inputAmount, outputAmount, impactPips] = result;
  return { inputAmount, outputAmount, impactPips };
}

// Usage
const WSEI = "0xE30feDd158A2e3b13e9badaeABaFc5516e95e8C7";
const USDC = "0xe15fC38F6D8c56aF07bbCBe3BAf5708A2Bf42392"; // 6 decimals

// Sell exactly 1 WSEI for USDC
const sell = await getQuote(WSEI, USDC, "1000000000000000000", "exactIn");
console.log("USDC out:", sell.outputAmount.toString());
console.log("Price impact (pips):", sell.impactPips.toString());

// Buy exactly 1 USDC with WSEI
const buy = await getQuote(WSEI, USDC, "1000000", "exactOut");
console.log("WSEI in:", buy.inputAmount.toString());
```

<Warning>
  The route returned by the API may change between calls as liquidity shifts. Always fetch a fresh route before quoting.
</Warning>

## Pools & Liquidity

### GET /api/v1/pools

Returns all pools above minimum TVL with tokens and incentives. No parameters.

<ResponseField name="tokens" type="array">
  Tokens in the pools: `address`, `name`, `symbol`, `usd_price`, `decimals`
</ResponseField>

<ResponseField name="incentives" type="array">
  Incentive programs for the listed pools, including ended ones (compare `end_time` with the current time). Same fields as `GET /api/v1/incentives`.
</ResponseField>

<ResponseField name="pools" type="array">
  Pool objects: `pool_address`, `token0_address`, `token1_address`, `first_token_reserve`, `second_token_reserve` (token units, not wei), `liquidity` (USD), `daily_volume`, `daily_fees` (USD, last 24 hours), `hourly_volume`, `hourly_fees` (USD, last 60 minutes, nullable), `hourly_swaps_count` (nullable), `type` (`"V2_POOL"` or `"V3_POOL"`), `fee_tier` (percent: `0.01`, `0.05`, `0.3` on `V3_POOL`; `0.3` on `V2_POOL`), `booster_farm_address` (nullable), `incentive_id` (nullable), `apy_booster`, `apr` (percent, `daily_fees × 365 / liquidity × 100`), `base_apr`, `boosted_apr`, `pool_created_at`, `liquidity_change_24h`, `volume_change_24h` (percent, nullable)
</ResponseField>

### GET /api/v1/pools/\{address\}

Single pool with incentives. Returns `pools` (a single object, despite the plural key) and `incentives` (this pool's programs, including ended ones). An unknown pool returns 404 `pool_not_found`.

### GET /api/v1/pools/\{address\}/stats

Historical snapshots. Query params `weekly`, `monthly`, `quarterly`, `all_time` are approximate downsampling targets: each reduces its series to roughly that many points; omitted or at least the stored count returns the full series. Values must be `1` or greater (`0` returns HTTP 500). `daily` is always returned in full.

Returns `liquidity_24h: { low, high }` (or `null`) and `stats: { daily, weekly, monthly, quarterly, all_time }` — each entry: `{ liquidity, daily_volume, hourly_volume, hourly_fees, hourly_swaps_count, created_at }`. `daily_volume` is the rolling 24-hour volume at snapshot time; the `hourly_*` fields are `null` in older snapshots. An unknown pool returns HTTP 200 with empty series and `liquidity_24h: null`.

### GET /api/v1/pools/\{address\}/transactions

The pool's 5,000 most recent swaps, newest first, plus 24-hour aggregate stats. No pagination — use `/activity` for full history. An unknown pool returns 404 `pool_not_found`.

Returns `transactions[]` and `stats: { tx_count, buy_volume_usd, sell_volume_usd, total_volume_usd, total_buys_count, total_sells_count, buyers_count, sellers_count, makers_count }`. `stats` covers the last 24 hours, not the returned array; `total_volume_usd` matches the pool's `daily_volume`, and `makers_count` counts unique buyers and sellers combined.

Transaction: `{ pool_address, first_token_address, second_token_address, first_amount_token, second_amount_token, block_number, tx_hash, from, total_value, type: "Swap", action: "Buy"|"Sell", created_at, pool_type: "v2"|"v3" }`. Amounts are in token units, `total_value` in USD. The first/second token is not always the pool's `token0`; it changes with `action`.

### GET /api/v1/pools/\{address\}/activity

Paginated pool activity using block cursors. Query: `swaps_from_block`, `mints_from_block`, `burns_from_block` (default `0`), each inclusive (`block_number` greater than or equal to the cursor). Returns `swaps[]`, `mints[]` and `burns[]`, at most 500 events each, oldest first. To fetch the next page, pass the `block_number` of the last event; because the cursor is inclusive, skip events you already have (for example by `tx_hash`). `mints` and `burns` are currently always empty. An unknown pool returns 404 `pool_not_found`.

## Tokens

### GET /api/v1/tokens

All tokens above TVL threshold. Each token: `address`, `name`, `symbol`, `usd_price`, `decimals`, `liquidity` (USD), `description` (nullable), `verified` (on the approved list), `category` (nullable: `wrapped`, `stablecoin`, `defi`, `lst`, `meme`, `native`, `ai`), `change: { hourly, daily, weekly, monthly }` (price change %), `liquidity_change_24h`, `volume_change_24h` (nullable), `sparkline_7d: [{ day, price }]` (7 daily USD prices, `day` as `YYYY-MM-DD`, oldest first)

### GET /api/v1/tokens/approved

Tokens on the official Dragonswap token list, included regardless of liquidity (some have `liquidity: 0`). Each: `address`, `name`, `symbol`, `usd_price`, `decimals`, `liquidity`, `daily_volume` (USD, last 24 hours), `daily_transactions` (cumulative count), `verified` (always `true`), `category`, `description`, `website` (nullable), `socials` (object with any of `x`, `telegram`, `discord`, `github`, or `null`), `liquidity_change_24h` and `volume_change_24h` (always `null` here).

### GET /api/v1/tokens/\{address\}

Single token. Returns a `token` object with the same fields as `/tokens/approved`; `verified` is `true` if the token is on the approved list, and `liquidity_change_24h` / `volume_change_24h` are populated (nullable). An unknown token returns 404 `token_not_found`.

### GET /api/v1/tokens/\{address\}/stats

Historical snapshots; no query params, every series returned in full. Returns `price_24h: { low, high }` and `stats: { daily, weekly, monthly, quarterly, all_time }` — each: `{ usd_price, liquidity, daily_volume, created_at }` (`daily_volume` is the rolling 24-hour volume at snapshot time). An unknown token returns 404 `token_not_found`.

## Stats & Transactions

### GET /api/v1/stats

Global DEX statistics in four buckets with the same structure: `stats.v2` (DEX V1 pools), `stats.v3` (DEX V2 pools), `stats.rfq` (RFQ trades) and `stats.all` (sum of the other three — use it for DEX-wide totals). Each bucket: `{ total_volume_usd, total_liquidity_usd, total_number_of_swaps, total_users_count, 24_hour_tx_count, 24_hour_fees_usd, 24_hour_volume_usd, hourly_data[], daily_data[] }`. `total_users_count` is the same in every bucket; in `rfq`, liquidity, inflows and outflows are `0`.

`hourly_data` covers the last 6 months; `daily_data` has one entry per UTC day, the last being the current, incomplete day. Both are oldest first, each entry: `{ created_at, volume_usd, total_liquidity_usd, inflows_usd, outflows_usd, fees_usd }` (`created_at` = start of the hour or day).

### GET /api/v1/transactions

The most recent swaps across all pools (currently 3,001), newest first. Returns `tokens[]` and `transactions[]` (same transaction shape as pool transactions).

### GET /api/v1/vol?address=\{wallet\}

Daily volume by wallet address. Response is date-keyed, newest first, one key per day on which the wallet swapped: `{ "2025-12-10": { volume_usd, swap_fee_usd, count } }`. It has no `status` field. A missing or invalid address, or a wallet with no swaps, returns HTTP 200 with an empty array `[]` (not an empty object).

## Farms

### GET /api/v1/farms

All farms, including ended ones (currently every farm has ended; keep farms whose `end_timestamp` is in the future; `apy` and `tvl` are still reported for ended farms). Returns `tokens[]` (reward, booster and pool tokens), `pools[]` (one per distinct `pooled_token_address`, same shape as List Pools), `farms[]`.

Farm: `farm_address`, `pooled_token_address` (the pool's LP token), `reward_token_address`, `booster_token_address` (`null` for basic), `apy` (percent), `tvl` (USD), `type` ("basic" | "boosted"), `unlock_rate` (reward tokens per second), `booster_unlock_rate` (`null` for basic), `is_lp_pooled_token`, `end_timestamp`, `start_timestamp`, `total_rewards_usd`, `campaign` (nullable, e.g. `"DS Epoch 2"`), `is_funded` (currently `null` for every farm)

### GET /api/v1/farms/\{address\}

Single farm. Returns `tokens[]` (reward token, plus booster token for boosted farms) and a `farm` object with the farm fields above except `is_funded`, plus `info` (HTML string or `null`). An unknown farm returns 404 `farm_not_found`.

### GET /api/v1/farms/\{address\}/history

Farm history. Returns `tokens[]` and `history[]` — all event types in one array, newest first, each: `{ type ("deposits"|"withdraws"|"payouts"), timestamp, user, pooled_token_address, block_number, farm_address, tx_hash }`. Deposits and withdraws add `amount`; payouts add `reward_token_claim` and `booster_token_claim` (`0` for basic farms); all in token units. No pagination, and each event type returns at most 1,000 records, so farms with more events are truncated. An unknown farm returns 404 `farm_not_found`.

### GET /api/v1/farms/\{address\}/stats

Historical stats: `stats: { daily, weekly, monthly, all_time }` — each: `{ created_at, deposits, deposits_usd }`

## Staking

All staking endpoints take the staking contract `0xb71886c52d754cf2b1d3d866c7cfe9eec01418a7` as `{address}` (or `{staker}`).

### GET /api/v1/staking/\{address\}

Upcoming reward emission times. Returns `emission_timestamps: number[]` (Unix seconds). The `{address}` segment is currently ignored; any value returns the same data.

### GET /api/v1/staking/\{address\}/emissions

Reward emissions (DRG or USDC) deposited into the staking contract — the same records as `protocol_rewards` in `/rewards`. Newest first, no pagination; any other address returns `deposits: []`. Each deposit: `{ tx_hash, token_address, amount, amount_wei, created_at, apr, reward_per_usd_staked, token_usd_price, buy_tx_hash }` — `token_address` is DRG (`0x0a526e425809aea71eb279d24ae22dee6c92a4fe`) or USDC (`0xe15fc38f6d8c56af07bbcbe3baf5708a2bf42392`); `amount` is a number in token units; `amount_wei` is a string; `created_at` is a Unix-seconds string; `apr` is in percent; `buy_tx_hash` is nullable.

### GET /api/v1/staking/\{address\}/rewards

Protocol rewards and fees; the `{address}` segment is currently ignored. Arrays are newest first and not paginated. Returns `fees: { total_withdrawal_fees_drg, total_marketplace_fees_drg, total_protocol_rewards_usd }`, `withdrawl_fees[]` (API spelling), `marketplace_fees[]`, `protocol_rewards[]`.

- Despite the `_drg` suffix, `total_withdrawal_fees_drg` and `total_marketplace_fees_drg` approximately match the USD value of the fee records, not the sum of `drg_fee`. `total_protocol_rewards_usd` is the sum of `amount` × `token_usd_price` over `protocol_rewards`.
- Fee records: `{ tx_hash, created_at, drg_fee, reward_per_usd_staked }` — `created_at` is a Unix-seconds string, `drg_fee` a number in DRG, `reward_per_usd_staked` a decimal string that may use exponent notation (e.g. `"8.1500662470371e-05"`).
- `protocol_rewards[]` has the same records as `deposits` in `/emissions`.

### GET /api/v1/staking/\{address\}/stats

Historical stats. Returns `total_staked` (DRG in token units; equals `total_deposits` of the latest snapshot) and `stats: { daily, weekly, monthly, all_time }` — each: `{ total_deposits, total_deposits_usd, total_fees, apr, created_at }` (`apr` in percent). `daily` has a snapshot about every 10 minutes (about 144), oldest first; `weekly` and `monthly` currently contain a single entry (the latest snapshot); `all_time` has irregular intervals, oldest first, ending with the latest. Any other address returns `total_staked: 0` and empty arrays.

### GET /api/v1/staking/\{address\}/activity/\{user\}

User activity. Returns `data: { reward_activity[], staking_activity[], marketplace_activity[], staking_bonus[] }`, newest first. Amounts are wei strings and timestamps are Unix-seconds strings.

- `reward_activity`: `{ type, user, token, token_operation, claimed_amount_wei, drg_amount_wei, usdc_amount_wei, tx_hash, timestamp }` — `type` is `"Claim"`, `"Compound"`, `"Autocompound"` or `"Autocompound Update"`; `token` is `"1"` (DRG) or `"2"` (USDC), `null` on `Autocompound Update`; `token_operation` is set on `Autocompound Update`; `claimed_amount_wei` on `Claim`; `drg_amount_wei` / `usdc_amount_wei` on `Compound` and `Autocompound`.
- `staking_activity`: `{ type, user, amount_wei, fees, tx_hash, timestamp }` — `type` is `"Deposit"`, `"Withdraw Start"` or `"Instant Withdraw"`; `fees` is set on `Instant Withdraw` only.
- `marketplace_activity`: `{ type, user, amount_wei, price_in_USDC_wei, bought_from, sold_to, tx_hash, timestamp }` — `type` is `"Listed"`, `"Price updated"`, `"Removed"`, `"Bought"` or `"Sold"`; `amount_wei` and `price_in_USDC_wei` are `null` on `Removed`; `bought_from` is set on `Bought`, `sold_to` on `Sold`.
- `staking_bonus`: `{ type: "Bonus", user, token, amount, amount_wei, amount_usd_value, tx_hash, timestamp }` — `token` is currently the staking contract address; `amount` and `amount_usd_value` are decimal strings.

A user with no staking history returns HTTP 200 with four empty arrays. Any `{address}` other than the staking contract returns 404 `staker_address_not_found`.

### GET /api/v1/staking/\{address\}/stats/\{user\}

User stats. Returns `stats: { total_DRG_earned, total_USDC_earned, total_staked } | null` — wei strings (DRG 18 decimals, USDC 6); `null` when the user has no staking history. Any `{address}` other than the staking contract returns 404 `staker_address_not_found`.

## User Data

### GET /api/v1/user/\{address\}/pools

User's liquidity positions across V2 and V3 pools. Returns `tokens[]` (both sides of every pool), `pools[]`, `incentives[]`. Each `V3_POOL` position is its own entry, so the same `pool_address` can appear more than once; entries have no position token ID or tick range. Each entry has the pool market fields from List Pools (`pool_created_at` nullable) plus `lp_balance` (`V2_POOL` only; absent on `V3_POOL`), `first_token_amount` and `second_token_amount` (token units), and `total_liquidity_usd` (USD value of the position). An invalid address returns HTTP 200 with empty arrays.

### GET /api/v1/user/\{address\}/portfolio

Portfolio overview. Returns `meta: { native_token_usd_price, change }`, `portfolio_history[]` (`{ timestamp, liquidity_usd, farm_balance_usd }`), `tokens[]` (with `user_balance` and `change`), `total_usd_value`, `native_token: { balance, usd_price }`.

- `meta` is SEI market data, the same for every wallet; `meta.change` (`hourly`, `daily`, `weekly`, `monthly`) is SEI's price change, not the portfolio's.
- `portfolio_history` is oldest first at irregular intervals (it can be a single entry); the last entry is close to the request time.
- `tokens` excludes native SEI (see `native_token`); `user_balance` and `native_token.balance` are in token units; `change` is the token's price change in percent.
- `total_usd_value` = token holdings + native SEI + `liquidity_usd` of the latest `portfolio_history` entry. Farm balances (`farm_balance_usd`) are **not** included.

An invalid address returns HTTP 500 with an HTML error page instead of JSON.

### GET /api/v1/user/\{address\}/farms

Farms where the user has a non-zero balance. Returns `tokens[]` (reward and booster tokens), `pools[]` (one per `pooled_token_address`), `farms[]` (farm fields as in List Farms, including `is_funded`). The balance itself is not returned — use the single-farm history or `farm_balance_usd` from the portfolio. An invalid address returns HTTP 200 with empty arrays.

### GET /api/v1/user/\{address\}/farms/\{farm\}

Single farm position with history. Returns `tokens[]`, `farm` (including `is_funded`), `history[]` (the user's events in this farm, newest first, same shape as farm history; `user` is lowercase) and `payouts: { reward_token_claims, total_booster_claims }` (sums of the user's claims in token units, `0` when none). A wallet with no activity in the farm returns HTTP 200 with an empty `history` and zero `payouts`; an unknown farm returns 404 `farm_not_found`.

### GET /api/v1/user/\{address\}/stakings/\{staker\}

User staking events. Returns `events[]` — each: `{ amount, deposited_at, transaction_hash, stake_index, unlock_timestamp, stake_locked_tx_hash, withdraw_tx_hash, emergency_withdraw_tx_hash, payouts[] }`. `amount` is a wei string; `stake_index` starts at `0`; the three `*_tx_hash` fields after `unlock_timestamp` are nullable. Payouts use camelCase keys: `{ amount (wei string), blockTimestamp (Unix-seconds string), rewardToken, transactionHash }`. The `{staker}` segment is currently ignored (any value returns the same events). A wallet with no stakes returns HTTP 200 with `events: []`.

## Incentives

### GET /api/v1/incentives

All incentive programs, including ended ones (compare `end_time` with the current time). Each: `start_time`, `end_time`, `reward` (number, reward-token units), `reward_token`, `refundee`, `pool`, `incentive_id`, `apr` (percent, as a decimal string; computed at request time and still non-zero after a program ends), `title` (nullable free text), `liquidity_usd` (decimal string), `owner` (nullable), `campaign` (nullable).

### GET /api/v1/incentives/\{incentive_id\}/tokens

Token IDs (integers) of the DEX V2 position NFTs staked in the program. Returns `token_ids[]`; an unknown or malformed ID returns HTTP 200 with an empty array.

### GET /api/v1/incentives/user/\{address\}

User participation. Returns `staked_tokens[]` (position NFT IDs staked in incentives), `deposited_tokens[]` (position NFT IDs deposited), `tokens[]`, `incentives[]`, `pools[]` (same shape as List Pools). A wallet with no positions returns HTTP 200 with empty arrays.

## Airdrops

### GET /api/v1/airdrops

All campaigns, including ended ones (after `ends_at`). Each: `name`, `address`, `token_address`, `number_of_users`, `timestamps[]` (vesting milestones in Unix seconds, one per vesting period — the same periods as `amounts` in the user allocation), `vesting_text`, `total_claimed`, `total_deposited`, `starts_at`, `ends_at`.

### GET /api/v1/airdrops/\{airdrop\}

Single campaign. Returns `airdrop` object. An unknown or malformed address returns 404 `{"status":"fail"}`.

### GET /api/v1/airdrops/\{airdrop\}/user/\{user\}

User allocation. Returns `is_eligible` (boolean), `amounts[]` (decimal strings in token units, one per entry of the airdrop's `timestamps`), `amounts_wei[]` (wei strings). A wallet that is not eligible, an invalid address, or an unknown airdrop returns HTTP 200 with `is_eligible: false` and empty arrays.

## Integration Checklist

1. Use `https://sei-api.dragonswap.app` as base URL; data endpoints are under `/api/v1/`, quotes under `/api/v4/`
2. For quoting: call `/api/v4/quote` first, then `SplitRouter.quoteExactInput()` or `quoteExactOutput()` via `simulateContract`
3. Map `data.dex.route` directly to the `SwapParams[]` struct
4. Set `minOutputAmount` / `maxInputAmount` to `0n`, `deadline: 0n`, `unwrap: false` for quote-only calls
5. For `exactOut`, take amounts from on-chain `quoteExactOutput`, not from the API response
6. Use `viem` with `sei` chain for on-chain interactions
7. Call the API from a server (CORS allowlist); responses can be cached for up to ~2 minutes
8. Check the HTTP status and `status` field; gateway 404 and 405 bodies are plain text, not JSON
9. Handle paginated endpoints (pool activity) using inclusive `block_number` cursors, deduplicating by `tx_hash`
10. Filter farms, incentives and airdrops by end time — the lists include ended programs
11. Pool and token stats return `{ daily, weekly, monthly, quarterly, all_time }`; staking stats return `{ daily, weekly, monthly, all_time }`
12. All timestamps are Unix timestamps (seconds); staking endpoints return them as strings
13. Token amounts are decimal-adjusted numbers; wei amounts are strings
14. USD values are numbers, except incentive `liquidity_usd` / `apr` and staking `amount_usd_value` (decimal strings); some fields are nullable
