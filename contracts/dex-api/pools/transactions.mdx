---
title: "Pool Transactions"
description: "Recent swap transactions for a specific pool with 24-hour aggregate stats"
api: "GET https://sei-api.dragonswap.app/api/v1/pools/{address}/transactions"
---

Returns the 5,000 most recent swaps for the pool, newest first, together with aggregate statistics for the last 24 hours. This endpoint has no pagination parameters; use [Pool Activity](/contracts/dex-api/pools/activity) to page through a pool's full swap history.

## Path Parameters

<ParamField path="address" type="string" required default="0x4cea29353508b81b6efbfb8d089efe808e8fc991">
  Pool contract address (case-insensitive).
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  Request status indicator: `ok` on success, `error` when the pool does not exist (HTTP 404).
</ResponseField>

<ResponseField name="transactions" type="array">
  Up to 5,000 of the pool's most recent swaps, sorted by `block_number` descending.

  <Expandable title="Transaction object">
    <ResponseField name="pool_address" type="string">
      Address of the pool where the swap occurred.
    </ResponseField>
    <ResponseField name="first_token_address" type="string">
      Address of the first token in the swap. This is not always the pool's `token0`; it changes from swap to swap together with `action`.
    </ResponseField>
    <ResponseField name="second_token_address" type="string">
      Address of the second token in the swap.
    </ResponseField>
    <ResponseField name="first_amount_token" type="number">
      Amount of the first token swapped, in whole token units (decimal-adjusted, not wei).
    </ResponseField>
    <ResponseField name="second_amount_token" type="number">
      Amount of the second token swapped, in whole token units (decimal-adjusted, not wei).
    </ResponseField>
    <ResponseField name="block_number" type="number">
      Block number in which the transaction was included.
    </ResponseField>
    <ResponseField name="tx_hash" type="string">
      Transaction hash.
    </ResponseField>
    <ResponseField name="from" type="string">
      Address that initiated the swap.
    </ResponseField>
    <ResponseField name="total_value" type="number">
      Total value of the swap in USD.
    </ResponseField>
    <ResponseField name="type" type="string">
      Transaction type: `Swap`.
    </ResponseField>
    <ResponseField name="action" type="string">
      Swap direction: `Buy` or `Sell`.
    </ResponseField>
    <ResponseField name="created_at" type="number">
      Time of the transaction, as a Unix timestamp (seconds).
    </ResponseField>
    <ResponseField name="pool_type" type="string">
      Pool version: `v3` or `v2`. `v2` = DEX V1 (constant-product) pool; `v3` = DEX V2 (concentrated-liquidity) pool.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stats" type="object">
  Aggregate statistics for the pool's swaps over the last 24 hours (not over the returned `transactions` array). `total_volume_usd` matches the pool's `daily_volume`.

  <Expandable title="Stats object">
    <ResponseField name="tx_count" type="number">
      Number of swaps in the last 24 hours.
    </ResponseField>
    <ResponseField name="buy_volume_usd" type="number">
      Buy volume over the last 24 hours, in USD.
    </ResponseField>
    <ResponseField name="sell_volume_usd" type="number">
      Sell volume over the last 24 hours, in USD.
    </ResponseField>
    <ResponseField name="total_volume_usd" type="number">
      Combined buy and sell volume over the last 24 hours, in USD.
    </ResponseField>
    <ResponseField name="total_buys_count" type="number">
      Number of buy swaps in the last 24 hours.
    </ResponseField>
    <ResponseField name="total_sells_count" type="number">
      Number of sell swaps in the last 24 hours.
    </ResponseField>
    <ResponseField name="buyers_count" type="number">
      Number of unique buyer addresses in the last 24 hours.
    </ResponseField>
    <ResponseField name="sellers_count" type="number">
      Number of unique seller addresses in the last 24 hours.
    </ResponseField>
    <ResponseField name="makers_count" type="number">
      Number of unique addresses (buyers and sellers combined) in the last 24 hours.
    </ResponseField>
  </Expandable>
</ResponseField>
