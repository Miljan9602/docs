---
title: "Staking Info"
description: "Returns the next reward emission timestamps for the staking contract"
api: "GET https://sei-api.dragonswap.app/api/v1/staking/{address}"
---

<Note>
  The `{address}` path segment is currently not used to filter results; any value returns the same data.
</Note>

## Path Parameters

<ParamField path="address" type="string" required default="0xb71886c52d754cf2b1d3d866c7cfe9eec01418a7">
  Staking contract address
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success
</ResponseField>

<ResponseField name="emission_timestamps" type="number[]">
  Upcoming reward emission times, each a Unix timestamp (seconds)
</ResponseField>

<ResponseExample>
```json 200 - Success
{
  "status": "ok",
  "emission_timestamps": [1795194000, 1795280400]
}
```
</ResponseExample>
