---
title: "Staking Emissions"
description: "Protocol reward emissions deposited into the staking contract"
api: "GET https://sei-api.dragonswap.app/api/v1/staking/{address}/emissions"
---

Returns the reward emissions (in DRG or USDC) deposited into the staking contract for distribution to stakers. These are the same records as `protocol_rewards` in the [Staking Rewards](/contracts/dex-api/staking/rewards) response. Records are returned newest first, with no pagination.

## Path Parameters

<ParamField path="address" type="string" required default="0xb71886c52d754cf2b1d3d866c7cfe9eec01418a7">
  Staking contract address. Any other address returns `"deposits": []`.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success
</ResponseField>

<ResponseField name="deposits" type="object[]">
  Reward emission records, newest first

  <Expandable title="Deposit object properties">
    <ResponseField name="tx_hash" type="string">
      Transaction hash of the emission
    </ResponseField>

    <ResponseField name="token_address" type="string">
      Reward token address: DRG (`0x0a526e425809aea71eb279d24ae22dee6c92a4fe`) or USDC (`0xe15fc38f6d8c56af07bbcbe3baf5708a2bf42392`)
    </ResponseField>

    <ResponseField name="amount" type="number">
      Human-readable emission amount
    </ResponseField>

    <ResponseField name="amount_wei" type="string">
      Emission amount in the token's smallest unit (18 decimals for DRG, 6 for USDC)
    </ResponseField>

    <ResponseField name="created_at" type="string">
      Unix timestamp in seconds, as a string
    </ResponseField>

    <ResponseField name="apr" type="number">
      Staking APR at the time of the emission, in percent
    </ResponseField>

    <ResponseField name="reward_per_usd_staked" type="number">
      Reward per USD staked
    </ResponseField>

    <ResponseField name="token_usd_price" type="number">
      USD price of the token at the time of the emission
    </ResponseField>

    <ResponseField name="buy_tx_hash" type="string | null">
      Transaction hash of the token buy, if applicable
    </ResponseField>
  </Expandable>
</ResponseField>
