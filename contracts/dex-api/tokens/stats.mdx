---
title: "Token Stats"
description: "Historical price, liquidity, and volume snapshots for a token over several lookback windows"
api: "GET https://sei-api.dragonswap.app/api/v1/tokens/{address}/stats"
---

Each series in `stats` is a list of snapshots taken over a lookback window, sorted oldest first. The last entry of every series is the most recent snapshot. This endpoint takes no query parameters and always returns every series in full.

| Series | Window |
|--------|--------|
| `daily` | Last 24 hours |
| `weekly` | Last 7 days |
| `monthly` | Last month |
| `quarterly` | Last 3 months |
| `all_time` | Last 12 months |

## Path Parameters

<ParamField path="address" type="string" required default="0xe30fedd158a2e3b13e9badaeabafc5516e95e8c7">
  Token contract address (case-insensitive).
</ParamField>

## Response

<ResponseField name="status" type="string">
  Request status indicator: `ok` on success, `fail` when the token is not found (HTTP 404).
</ResponseField>

<ResponseField name="price_24h" type="object">
  Lowest and highest USD price across the `daily` series.

  <Expandable title="price_24h">
    <ResponseField name="low" type="number">
      Lowest USD price over the last 24 hours.
    </ResponseField>
    <ResponseField name="high" type="number">
      Highest USD price over the last 24 hours.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stats" type="object">
  Snapshot series grouped by lookback window.

  <Expandable title="Stats object">
    <ResponseField name="daily" type="array">
      Snapshots from the last 24 hours.

      <Expandable title="Snapshot object">
        <ResponseField name="usd_price" type="number">
          USD price at the time of the snapshot.
        </ResponseField>
        <ResponseField name="liquidity" type="number">
          Total liquidity in USD at the time of the snapshot.
        </ResponseField>
        <ResponseField name="daily_volume" type="number">
          Rolling 24-hour trading volume in USD at the time of the snapshot (not the volume of the series window).
        </ResponseField>
        <ResponseField name="created_at" type="number">
          Snapshot time, as a Unix timestamp (seconds).
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="weekly" type="array">
      Snapshots from the last 7 days. Same structure as `daily`.
    </ResponseField>

    <ResponseField name="monthly" type="array">
      Snapshots from the last month. Same structure as `daily`.
    </ResponseField>

    <ResponseField name="quarterly" type="array">
      Snapshots from the last 3 months. Same structure as `daily`.
    </ResponseField>

    <ResponseField name="all_time" type="array">
      Snapshots from the last 12 months. Despite the name, older history is not included. Same structure as `daily`.
    </ResponseField>
  </Expandable>
</ResponseField>
