## Overview

Getting a swap quote is a two-step process:

1. **Route Discovery** — Call the Dragonswap routing API to find the optimal swap path across V1 and V2 pools
2. **On-chain Quote** — Pass the route into `DragonswapSplitRouter.quoteExactInput()` (or `quoteExactOutput()`) via `eth_call` to get the expected amounts and price impact

```
User wants to swap Token A → Token B

Step 1: GET /api/v4/quote → returns optimal route (pool hops) + API-side amounts
Step 2: eth_call SplitRouter.quoteExactInput(route) / quoteExactOutput(route) → returns inputAmount, outputAmount, impactPips
Step 3: (optional) Execute swap via SplitRouter.exactInput(route) / exactOutput(route)
```

## Step 1 — Route Discovery API

```
GET https://sei-api.dragonswap.app/api/v4/quote
```

Finds the optimal swap route across all available Dragonswap pools and returns the expected amounts for that route.

### Query Parameters

<ParamField query="amount" type="string" required>
  Amount in the token's smallest unit, as a base-10 integer string (e.g. `1000000000000000000` = 1 WSEI, `1000000` = 1 USDC). For `exactIn` this is the input amount; for `exactOut` it is the desired output amount. A non-integer value or `0` returns a `500` error.
</ParamField>

<ParamField query="tokenInAddress" type="string" required>
  Input token contract address (0x-prefixed). Use the EIP-55 checksummed form or all-lowercase — a mixed-case address with an invalid checksum returns `400` `Not an address`.
</ParamField>

<ParamField query="tokenOutAddress" type="string" required>
  Output token contract address (0x-prefixed). Same format rules as `tokenInAddress`.
</ParamField>

<ParamField query="type" type="string" required>
  Quote direction: `exactIn` or `exactOut` (case-sensitive). The value is not validated as an enum — any other value (e.g. `exactout`) is quoted as `exactIn`.
</ParamField>

### Response

<ResponseField name="status" type="string">
  `"success"` or `"error"`
</ResponseField>

<ResponseField name="type" type="string">
  Quote source. `"dex"` for a route through Dragonswap pools, described by the `dex` object.
</ResponseField>

<ResponseField name="dex" type="object">
  The routing result.
</ResponseField>

<ResponseField name="dex.inputAmount" type="string">
  Input amount in wei of `tokenInAddress`. For `exactIn` this equals `amount`. Do not use it for `exactOut` quotes — see the warning below.
</ResponseField>

<ResponseField name="dex.outputAmount" type="string">
  Expected output amount in wei of `tokenOutAddress`. Do not use it for `exactOut` quotes — see the warning below.
</ResponseField>

<ResponseField name="dex.impactPips" type="string">
  Price impact in millionths (`1000000` = 100%, `10000` = 1%), excluding LP fees. Same scale as `impactPips` returned on-chain.
</ResponseField>

<ResponseField name="dex.route" type="array">
  Array of pool hops defining the swap path. Each hop maps directly to a `SwapParams` struct and contains:
  - `pool` (string) — Pool contract address (EIP-55 checksummed)
  - `poolType` (number) — `0` = V1, `1` = V2
  - `inputToken` (string) — Input token address for this hop
  - `outputToken` (string) — Output token address for this hop
  - `feePips` (number) — Pool fee in pips (1 pip = 0.0001%, so `3000` = 0.3%)
  - `inputPercentage` (number) — Share (0–100) of the remaining, not-yet-routed balance of `inputToken` that this hop takes. Hops are applied in route order, so a 95% / 5% split of the input shows up as `95` on the first hop and `100` on the hop that takes the remaining 5%.
  - `outputPercentage` (number) — Output-side split value used by the SplitRouter. Pass it through unchanged; for the share of the total handled by each path, see `dex.linearSubroutes`.
</ResponseField>

<ResponseField name="dex.linearSubroutes" type="array">
  Per-path view of the route. Each subroute contains:
  - `percentage` (number) — Share (0–100) of the total swap going through this path
  - `swaps` (array) — Hops on this path, with the same fields as `dex.route` minus the percentage fields
</ResponseField>

<ResponseField name="rfq" type="null">
  `null` in DEX responses (`type: "dex"`). RFQ quotes are documented in the [RFQ section](/frontend/getting-started).
</ResponseField>

<ResponseField name="rfqConfig" type="null">
  `null` in DEX responses (`type: "dex"`).
</ResponseField>

<ResponseField name="unwrap" type="boolean">
  Included in `exactIn` responses; omitted from `exactOut` responses.
</ResponseField>

<ResponseField name="message" type="array | string">
  Only when `status` is `"error"`. An array of validation issues (HTTP `400`), or a string (HTTP `500`) — returned, for example, when no route exists between the two tokens or `amount` is `0` or not an integer.
</ResponseField>

<Warning>
  For `exactOut` quotes, do not use `dex.inputAmount` or `dex.outputAmount`: `dex.outputAmount` can be lower than the requested `amount`, and `dex.inputAmount` can be lower than the input actually required. Use `dex.route` and get the amounts from on-chain `quoteExactOutput` (Step 2 below).
</Warning>

<Info>
  For `exactIn` quotes, `dex.outputAmount` and `dex.impactPips` match what `quoteExactInput` returns for the same route at the time of the request, so Step 2 is optional for displaying a quote. Re-quote on-chain right before executing a swap, since pool state changes every block.
</Info>

## Step 2 — On-chain Quote via SplitRouter

Use the route from Step 1 to get an exact quote from the `DragonswapSplitRouter` contract. This is a read-only call (`eth_call` / `simulateContract`) — no transaction is submitted. The quote functions are declared `nonpayable` rather than `view`, which is why the examples use `simulateContract`.

**Contract:** [`0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199`](https://seitrace.com/address/0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199)

### Functions

| Function | Direction | Input Struct |
|---|---|---|
| `quoteExactInput(ExactInputParams)` | exactIn | `ExactInputParams` |
| `quoteExactOutput(ExactOutputParams)` | exactOut | `ExactOutputParams` |

Both return: `(uint256 inputAmount, uint256 outputAmount, uint256 impactPips)`

`impactPips` is the price impact in millionths (`1000000` = 100%, so `7744` ≈ 0.77%), excluding LP fees.

### Structs

**`ExactInputParams`**
| Field | Type | Description |
|---|---|---|
| `inputAmount` | `uint256` | Amount of input token in wei |
| `minOutputAmount` | `uint256` | Set to `0` for quoting |
| `deadline` | `uint256` | Set to `0` for quoting |
| `unwrap` | `bool` | Set to `false` for quoting |
| `route` | `SwapParams[]` | Array of swap hops from the route API |

**`ExactOutputParams`**
| Field | Type | Description |
|---|---|---|
| `outputAmount` | `uint256` | Desired amount of output token in wei |
| `maxInputAmount` | `uint256` | Set to `0` for quoting |
| `deadline` | `uint256` | Set to `0` for quoting |
| `unwrap` | `bool` | Set to `false` for quoting |
| `route` | `SwapParams[]` | Array of swap hops from the route API |

**`SwapParams`**
| Field | Type | Description |
|---|---|---|
| `poolType` | `uint8` | `0` = V1, `1` = V2 |
| `pool` | `address` | Pool contract address |
| `inputToken` | `address` | Input token address for this hop |
| `outputToken` | `address` | Output token address for this hop |
| `feePips` | `uint24` | Fee in pips |
| `inputPercentage` | `uint8` | Input percentage for this hop |
| `outputPercentage` | `uint8` | Output percentage for this hop |

<Info>
  `minOutputAmount`, `maxInputAmount`, `deadline`, and `unwrap` are **ignored** during quoting — set them to `0n`, `0n`, `0n`, and `false` respectively.
</Info>

### Mapping Route API Response to SwapParams

Each entry in `dex.route` maps directly to a `SwapParams` struct:

```typescript
type SwapParams = {
  poolType: number;
  pool: `0x${string}`;
  inputToken: `0x${string}`;
  outputToken: `0x${string}`;
  feePips: number;
  inputPercentage: number;
  outputPercentage: number;
};

const route: SwapParams[] = data.dex.route.map((hop: SwapParams) => ({
  poolType: hop.poolType,
  pool: hop.pool,
  inputToken: hop.inputToken,
  outputToken: hop.outputToken,
  feePips: hop.feePips,
  inputPercentage: hop.inputPercentage,
  outputPercentage: hop.outputPercentage,
}));
```

### Full Example (viem/TypeScript)

```typescript
import { createPublicClient, http, parseAbi } from "viem";
import { sei } from "viem/chains";

const publicClient = createPublicClient({
  chain: sei,
  transport: http(),
});

const SPLIT_ROUTER = "0xCaCbF14f07AF3Be93C6fc8bF0a43f9279F792199" as const;

const splitRouterAbi = parseAbi([
  "struct SwapParams { uint8 poolType; address pool; address inputToken; address outputToken; uint24 feePips; uint8 inputPercentage; uint8 outputPercentage; }",
  "struct ExactInputParams { uint256 inputAmount; uint256 minOutputAmount; uint256 deadline; bool unwrap; SwapParams[] route; }",
  "struct ExactOutputParams { uint256 outputAmount; uint256 maxInputAmount; uint256 deadline; bool unwrap; SwapParams[] route; }",
  "function quoteExactInput(ExactInputParams params) external returns (uint256 inputAmount, uint256 outputAmount, uint256 impactPips)",
  "function quoteExactOutput(ExactOutputParams params) external returns (uint256 inputAmount, uint256 outputAmount, uint256 impactPips)",
]);

type SwapParams = {
  poolType: number;
  pool: `0x${string}`;
  inputToken: `0x${string}`;
  outputToken: `0x${string}`;
  feePips: number;
  inputPercentage: number;
  outputPercentage: number;
};

type RouteResponse =
  | { status: "success"; dex: { route: SwapParams[] } }
  | { status: "error"; message: unknown };

async function getQuote(
  tokenIn: string,
  tokenOut: string,
  amount: string,
  type: "exactIn" | "exactOut"
) {
  // Step 1: Get optimal route from the API
  const params = new URLSearchParams({
    amount,
    tokenInAddress: tokenIn,
    tokenOutAddress: tokenOut,
    type,
  });

  const res = await fetch(
    `https://sei-api.dragonswap.app/api/v4/quote?${params}`
  );
  const data = (await res.json()) as RouteResponse;

  if (data.status !== "success") {
    throw new Error(`Route discovery failed: ${JSON.stringify(data.message)}`);
  }

  // Map API route to SwapParams structs
  const route = data.dex.route.map((hop) => ({
    poolType: hop.poolType,
    pool: hop.pool,
    inputToken: hop.inputToken,
    outputToken: hop.outputToken,
    feePips: hop.feePips,
    inputPercentage: hop.inputPercentage,
    outputPercentage: hop.outputPercentage,
  }));

  // Step 2: Call the on-chain quote function
  if (type === "exactIn") {
    const { result } = await publicClient.simulateContract({
      address: SPLIT_ROUTER,
      abi: splitRouterAbi,
      functionName: "quoteExactInput",
      args: [
        {
          inputAmount: BigInt(amount),
          minOutputAmount: 0n,
          deadline: 0n,
          unwrap: false,
          route,
        },
      ],
    });

    const [inputAmount, outputAmount, impactPips] = result;
    return { inputAmount, outputAmount, impactPips };
  }

  const { result } = await publicClient.simulateContract({
    address: SPLIT_ROUTER,
    abi: splitRouterAbi,
    functionName: "quoteExactOutput",
    args: [
      {
        outputAmount: BigInt(amount),
        maxInputAmount: 0n,
        deadline: 0n,
        unwrap: false,
        route,
      },
    ],
  });

  const [inputAmount, outputAmount, impactPips] = result;
  return { inputAmount, outputAmount, impactPips };
}

// Usage
const WSEI = "0xE30feDd158A2e3b13e9badaeABaFc5516e95e8C7";
const USDC = "0xe15fC38F6D8c56aF07bbCBe3BAf5708A2Bf42392"; // 6 decimals

// Sell exactly 1 WSEI for USDC
const sell = await getQuote(WSEI, USDC, "1000000000000000000", "exactIn");
console.log("USDC out:", sell.outputAmount.toString());
console.log("Price impact (pips):", sell.impactPips.toString());

// Buy exactly 1 USDC with WSEI
const buy = await getQuote(WSEI, USDC, "1000000", "exactOut");
console.log("WSEI in:", buy.inputAmount.toString());
```

<Warning>
  The route returned by the API may change between calls as liquidity shifts. Always fetch a fresh route before quoting.
</Warning>
