---
title: "Incentive Tokens"
description: "Position token IDs staked in a specific incentive program"
api: "GET https://sei-api.dragonswap.app/api/v1/incentives/{incentive_id}/tokens"
---

## Path Parameters

<ParamField path="incentive_id" type="string" required default="0xbddb5830bc2e81d53e1e69c2c3c8d4a2f163c90b0a150ffc7e5006d2d9cf7b71">
  Unique incentive identifier (the `incentive_id` from [List Incentives](/contracts/dex-api/incentives/list)). An unknown or malformed ID returns `200` with an empty `token_ids` array.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  Request status indicator.
</ResponseField>

<ResponseField name="token_ids" type="array">
  Token IDs (integers) of the DEX V2 (concentrated-liquidity) position NFTs staked in the incentive program. Empty array when none are staked.
</ResponseField>

<ResponseExample>
```json 200 - Success
{
  "status": "ok",
  "token_ids": [251932, 251934]
}
```

```json 200 - No Staked Positions
{
  "status": "ok",
  "token_ids": []
}
```
</ResponseExample>
