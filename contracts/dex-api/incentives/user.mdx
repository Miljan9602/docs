---
title: "User Incentives"
description: "Incentive program participation for a specific user"
api: "GET https://sei-api.dragonswap.app/api/v1/incentives/user/{address}"
---

## Path Parameters

<ParamField path="address" type="string" required>
  User wallet address (case-insensitive). A wallet with no positions (or a value that is not a valid address) returns `200` with empty arrays.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  Request status indicator.
</ResponseField>

<ResponseField name="staked_tokens" type="array">
  Token IDs (integers) of the user's DEX V2 (concentrated-liquidity) position NFTs that are staked in incentive programs.
</ResponseField>

<ResponseField name="deposited_tokens" type="array">
  Token IDs (integers) of DEX V2 position NFTs the user has deposited.
</ResponseField>

<ResponseField name="tokens" type="array">
  Tokens of the pools in `pools`. Each entry includes `address`, `name`, `symbol`, `usd_price`, and `decimals`.
</ResponseField>

<ResponseField name="incentives" type="array">
  Incentive programs the user is participating in.
</ResponseField>

<ResponseField name="pools" type="array">
  Pools of the user's deposited or staked positions, with the same market fields as [List Pools](/contracts/dex-api/pools/list). `type` is `"V2_POOL"` or `"V3_POOL"`: `V2_POOL` = DEX V1 (constant-product) pool; `V3_POOL` = DEX V2 (concentrated-liquidity) pool.
</ResponseField>
