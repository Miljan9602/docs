---
title: "List Incentives"
description: "Returns all active and past incentive programs"
api: "GET https://sei-api.dragonswap.app/api/v1/incentives"
---

No parameters are required for this endpoint. Programs stay in the list after they end; compare `end_time` with the current time to find active ones.

## Response Fields

<ResponseField name="status" type="string">
  Request status indicator.
</ResponseField>

<ResponseField name="incentives" type="array">
  Array of incentive program objects.

  <Expandable title="Incentive object properties">
    <ResponseField name="start_time" type="number">
      Program start, as a Unix timestamp (seconds).
    </ResponseField>

    <ResponseField name="end_time" type="number">
      Program end, as a Unix timestamp (seconds).
    </ResponseField>

    <ResponseField name="reward" type="number">
      Total reward amount for the program, in reward-token units (not wei).
    </ResponseField>

    <ResponseField name="reward_token" type="string">
      Contract address of the reward token.
    </ResponseField>

    <ResponseField name="refundee" type="string">
      Address that receives any unclaimed rewards after the program ends.
    </ResponseField>

    <ResponseField name="pool" type="string">
      Contract address of the liquidity pool associated with the incentive.
    </ResponseField>

    <ResponseField name="incentive_id" type="string">
      Unique identifier for the incentive program.
    </ResponseField>

    <ResponseField name="apr" type="string">
      Annual percentage rate in percent, as a decimal string (`"123.92"` = 123.92%). Computed at request time, so it changes between requests, and it is still returned (non-zero) for programs that have ended. Check `end_time` before treating it as a live rate.
    </ResponseField>

    <ResponseField name="title" type="string | null">
      Free-text display title set for the program (often a token pair such as `"WETH / USDC"`, but not derived from the pool), or `null`.
    </ResponseField>

    <ResponseField name="liquidity_usd" type="string">
      Total liquidity in USD currently staked in the incentive, as a decimal string.
    </ResponseField>

    <ResponseField name="owner" type="string | null">
      Address of the incentive program owner, or `null`.
    </ResponseField>

    <ResponseField name="campaign" type="string | null">
      Associated campaign identifier, or `null`.
    </ResponseField>
  </Expandable>
</ResponseField>
