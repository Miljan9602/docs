---
title: "List Farms"
description: "Returns all yield farms, including ended ones, with their associated tokens and pools"
api: "GET https://sei-api.dragonswap.app/api/v1/farms"
---

<Note>
  The response includes farms that have already ended; currently every returned farm has ended (the latest `end_timestamp` is `1758535904`, 2025-09-22). To find active farms, keep only farms whose `end_timestamp` is in the future. `apy` and `tvl` are still reported for ended farms.
</Note>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success
</ResponseField>

<ResponseField name="tokens" type="object[]">
  Every reward token, booster token and pool token referenced by the farms and pools in this response

  <Expandable title="Token object properties">
    <ResponseField name="address" type="string">
      Token contract address
    </ResponseField>

    <ResponseField name="name" type="string">
      Token name
    </ResponseField>

    <ResponseField name="symbol" type="string">
      Token symbol
    </ResponseField>

    <ResponseField name="usd_price" type="number">
      Current USD price
    </ResponseField>

    <ResponseField name="decimals" type="number">
      Token decimals
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pools" type="object[]">
  The pools whose LP tokens are staked in the farms (one per distinct `pooled_token_address`), with the same shape as pools in [List Pools](/contracts/dex-api/pools/list). `type` is `"V2_POOL"` or `"V3_POOL"`: `V2_POOL` = DEX V1 (constant-product) pool; `V3_POOL` = DEX V2 (concentrated-liquidity) pool.
</ResponseField>

<ResponseField name="farms" type="object[]">
  Array of farm objects

  <Expandable title="Farm object properties">
    <ResponseField name="farm_address" type="string">
      Farm contract address
    </ResponseField>

    <ResponseField name="pooled_token_address" type="string">
      Address of the staked token (the pool's LP token)
    </ResponseField>

    <ResponseField name="reward_token_address" type="string">
      Reward token address
    </ResponseField>

    <ResponseField name="booster_token_address" type="string | null">
      Booster token address. `null` for `basic` farms.
    </ResponseField>

    <ResponseField name="apy" type="number">
      Annual percentage yield, in percent
    </ResponseField>

    <ResponseField name="tvl" type="number">
      Total value locked in USD
    </ResponseField>

    <ResponseField name="type" type="string">
      Farm type: `"basic"` or `"boosted"`
    </ResponseField>

    <ResponseField name="unlock_rate" type="number">
      Reward tokens unlocked per second
    </ResponseField>

    <ResponseField name="booster_unlock_rate" type="number | null">
      Booster tokens unlocked per second. `null` for `basic` farms.
    </ResponseField>

    <ResponseField name="is_lp_pooled_token" type="boolean">
      Whether the staked token is an LP token
    </ResponseField>

    <ResponseField name="end_timestamp" type="number">
      Farm end time, Unix timestamp (seconds)
    </ResponseField>

    <ResponseField name="start_timestamp" type="number">
      Farm start time, Unix timestamp (seconds)
    </ResponseField>

    <ResponseField name="total_rewards_usd" type="number">
      Total rewards value in USD
    </ResponseField>

    <ResponseField name="campaign" type="string | null">
      Campaign name, e.g. `"DS Epoch 2"`
    </ResponseField>

    <ResponseField name="is_funded" type="boolean | null">
      Whether the farm is funded. Currently `null` for every farm.
    </ResponseField>
  </Expandable>
</ResponseField>
