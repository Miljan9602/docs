---
title: "Farm History"
description: "Transaction history for a farm (deposits, withdrawals, payouts)"
api: "GET https://sei-api.dragonswap.app/api/v1/farms/{address}/history"
---

<Note>
  Events of all types are returned in a single array, newest first. There is no pagination, and each event type (`deposits`, `withdraws`, `payouts`) returns at most 1000 records. When a farm has more events of a type than that, the response does not contain all of them.
</Note>

## Path Parameters

<ParamField path="address" type="string" required default="0x256df69a9a1e7ccd48ffc4211fcaba39a56635a9">
  Farm contract address (case-insensitive)
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success
</ResponseField>

<ResponseField name="tokens" type="object[]">
  The farm's reward token and, for `boosted` farms, its booster token. Each has `address`, `name`, `symbol`, `usd_price` (number) and `decimals` (number).
</ResponseField>

<ResponseField name="history" type="object[]">
  Farm events, newest first

  <Expandable title="Event object properties">
    <ResponseField name="type" type="string">
      Event type: `"deposits"`, `"withdraws"`, or `"payouts"`
    </ResponseField>

    <ResponseField name="timestamp" type="number">
      Unix timestamp (seconds)
    </ResponseField>

    <ResponseField name="user" type="string">
      User wallet address
    </ResponseField>

    <ResponseField name="pooled_token_address" type="string">
      Staked (LP) token address
    </ResponseField>

    <ResponseField name="block_number" type="number">
      Block number
    </ResponseField>

    <ResponseField name="farm_address" type="string">
      Farm contract address
    </ResponseField>

    <ResponseField name="tx_hash" type="string">
      Transaction hash
    </ResponseField>

    <ResponseField name="amount" type="number">
      Staked token amount (human-readable). Present on `deposits` and `withdraws` events only.
    </ResponseField>

    <ResponseField name="reward_token_claim" type="number">
      Reward tokens claimed (human-readable). Present on `payouts` events only.
    </ResponseField>

    <ResponseField name="booster_token_claim" type="number">
      Booster tokens claimed (human-readable). Present on every `payouts` event; `0` for `basic` farms.
    </ResponseField>
  </Expandable>
</ResponseField>
