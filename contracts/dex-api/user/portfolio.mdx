---
title: "User Portfolio"
description: "Portfolio overview including historical value, token holdings, and total USD value"
api: "GET https://sei-api.dragonswap.app/api/v1/user/{address}/portfolio"
---

## Path Parameters

<ParamField path="address" type="string" required>
  User wallet address (case-insensitive). A value that is not a valid address returns HTTP `500` with an HTML error page instead of JSON.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success
</ResponseField>

<ResponseField name="meta" type="object">
  Native-token market data. The same for every wallet.

  <Expandable title="Meta object">
    <ResponseField name="native_token_usd_price" type="number">
      Current USD price of SEI.
    </ResponseField>
    <ResponseField name="change" type="object">
      SEI price change in percent, with `hourly`, `daily`, `weekly`, and `monthly` keys. This is the native token's price change, not the change in the user's portfolio value.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="portfolio_history" type="array">
  Snapshots of the user's LP and farm value, oldest first. Snapshots are not taken at a fixed interval: a frequently tracked wallet can have entries a few hours apart, while a wallet with little history may have a single entry. The last entry is close to the time of the request.

  <Expandable title="Snapshot object">
    <ResponseField name="timestamp" type="number">
      Snapshot time, as a Unix timestamp (seconds).
    </ResponseField>
    <ResponseField name="liquidity_usd" type="number">
      USD value of the user's liquidity positions at that time.
    </ResponseField>
    <ResponseField name="farm_balance_usd" type="number">
      USD value of the user's farm balances at that time.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tokens" type="array">
  The user's token holdings (excluding native SEI, which is reported in `native_token`).

  <Expandable title="Token object">
    <ResponseField name="address" type="string">
      Token contract address.
    </ResponseField>
    <ResponseField name="name" type="string">
      Full token name.
    </ResponseField>
    <ResponseField name="symbol" type="string">
      Token ticker symbol.
    </ResponseField>
    <ResponseField name="usd_price" type="number">
      Current USD price of the token.
    </ResponseField>
    <ResponseField name="decimals" type="number">
      Number of decimals the token uses.
    </ResponseField>
    <ResponseField name="change" type="object">
      Token price change in percent, with `hourly`, `daily`, `weekly`, and `monthly` keys.
    </ResponseField>
    <ResponseField name="user_balance" type="number">
      The user's balance, in token units (not wei).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total_usd_value" type="number">
  Total USD value: the token holdings in `tokens`, plus the native SEI balance, plus `liquidity_usd` from the latest `portfolio_history` entry. Farm balances (`farm_balance_usd`) are **not** included.
</ResponseField>

<ResponseField name="native_token" type="object">
  The user's native SEI holding.

  <Expandable title="Native token object">
    <ResponseField name="balance" type="number">
      SEI balance, in token units (not wei).
    </ResponseField>
    <ResponseField name="usd_price" type="number">
      Current USD price of SEI.
    </ResponseField>
  </Expandable>
</ResponseField>
