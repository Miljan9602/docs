---
title: "User Single Farm"
description: "A user's position and history for a specific farm"
api: "GET https://sei-api.dragonswap.app/api/v1/user/{address}/farms/{farm}"
---

## Path Parameters

<ParamField path="address" type="string" required>
  User wallet address (case-insensitive). A wallet with no activity in the farm (or a value that is not a valid address) returns `200` with an empty `history` and zero `payouts`.
</ParamField>

<ParamField path="farm" type="string" required default="0x256df69a9a1e7ccd48ffc4211fcaba39a56635a9">
  Farm contract address. An unknown farm returns `404` with `farm_not_found`.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `"ok"` on success, `"error"` on failure
</ResponseField>

<ResponseField name="tokens" type="array">
  The farm's reward and booster tokens. Each entry includes `address`, `name`, `symbol`, `usd_price`, and `decimals`.
</ResponseField>

<ResponseField name="farm" type="object">
  Farm details: `farm_address`, `pooled_token_address`, `reward_token_address`, `booster_token_address` (string | null), `apy`, `tvl`, `type` (`"basic"` or `"boosted"`), `unlock_rate`, `booster_unlock_rate` (number | null), `is_lp_pooled_token`, `start_timestamp`, `end_timestamp`, `total_rewards_usd`, `campaign` (string | null), and `is_funded` (boolean | null). Same shape as the farm objects in [User Farms](/contracts/dex-api/user/farms).
</ResponseField>

<ResponseField name="history" type="array">
  The user's interactions with this farm, newest first.

  <Expandable title="History entry">
    <ResponseField name="type" type="string">
      Event type: `"deposits"`, `"withdraws"`, or `"payouts"`.
    </ResponseField>
    <ResponseField name="timestamp" type="number">
      Event time, as a Unix timestamp (seconds).
    </ResponseField>
    <ResponseField name="user" type="string">
      User wallet address (lowercase).
    </ResponseField>
    <ResponseField name="amount" type="number">
      Amount of the pooled token deposited or withdrawn, in token units (not wei). Present on `deposits` and `withdraws` entries only; absent on `payouts`.
    </ResponseField>
    <ResponseField name="reward_token_claim" type="number">
      Reward tokens claimed, in token units. Present on `payouts` entries only.
    </ResponseField>
    <ResponseField name="booster_token_claim" type="number">
      Booster tokens claimed, in token units. Present on `payouts` entries only.
    </ResponseField>
    <ResponseField name="pooled_token_address" type="string">
      Address of the farm's pooled token.
    </ResponseField>
    <ResponseField name="farm_address" type="string">
      Farm contract address.
    </ResponseField>
    <ResponseField name="block_number" type="number">
      Block number of the transaction.
    </ResponseField>
    <ResponseField name="tx_hash" type="string">
      Transaction hash.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="payouts" type="object">
  The user's payout totals for this farm (the sums of `reward_token_claim` and `booster_token_claim` across the user's `payouts` entries).

  <Expandable title="Payouts object">
    <ResponseField name="reward_token_claims" type="number">
      Total reward tokens claimed, in token units. `0` when the user has no payouts.
    </ResponseField>
    <ResponseField name="total_booster_claims" type="number">
      Total booster tokens claimed, in token units. `0` when the user has no payouts.
    </ResponseField>
  </Expandable>
</ResponseField>
